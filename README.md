# IRP Web Development Assignment

## Project Overview
This project is developed as part of the IRP Web Development Assignment. It demonstrates responsive web design using HTML and CSS, along with core JavaScript concepts.

## Project Structure
```text
irp-web-development-assignment/
│
├── part-a-responsive-ui/
│   ├── index.html
│   └── style.css
│
├── part-b-javascript/
│   └── bank.js
│
└── README.md
```

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Node.js (to execute JavaScript)

## Part A: Responsive Web Design
Created a responsive IRP LMS homepage using:
- Semantic HTML5 elements
- CSS Flexbox and Grid
- Media queries for responsive layouts
- Sticky navigation bar
- Responsive hero section
- Learning Journey cards

### How to Run
1. Open the project folder in VS Code.
2. Open `part-a-responsive-ui/index.html`.
3. Right-click and select **Open with Live Server**, or open the HTML file directly in a browser.

### Responsive Testing
Test the webpage at different screen sizes:
- Desktop: 1200px and above
- Tablet: 768px to 1024px
- Mobile: 375px or 390px

## Part B: JavaScript Fundamentals
Implemented JavaScript concepts using a banking-related example.

Topics covered:
- Type conversion and type coercion
- Strict mode
- `parseAmount()` function and input validation
- `var`, `let`, and `const`
- Hoisting and Temporal Dead Zone (TDZ)
- Function declarations and function expressions
- Asynchronous loops using `setTimeout`

### How to Run
Open the VS Code terminal in the main project folder and execute:

```bash
node part-b-javascript/bank.js
```

The output will display the input validation results, hoisting examples, and asynchronous loop behavior.
